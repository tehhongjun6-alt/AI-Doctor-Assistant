# Consultation Backend

Node.js, Express and TypeScript API for nearby hospital search with Geoapify.

## Setup

1. Copy `.env.example` to `.env`.
2. Add a Geoapify API key.
3. Run `npm install`.
4. Run `npm run dev`.

The API starts on `http://127.0.0.1:8002` by default.

## Endpoints

- `GET /health`
- `POST /api/hospitals/nearby`
